# sound_rs benchmark

arm, Darwin 25.6.0, Python 3.14.7, reps=10, 2026-11-12T17:49:10

Hardware: Apple M5 Pro, 24 GB, macOS 26.6.2. Competitors: soundfile 0.14
(libsndfile 1.2.2), sounddevice 0.5.6 (PortAudio), miniaudio 1.73, librosa 0.11,
pydub 0.25.1 with ffmpeg. Decode workers return float32; pydub and miniaudio are
converted from int16.

## Summary

| scenario | sound_rs | closest competitor | note |
|---|---|---|---|
| import, cold | **0.99 ms** | 28.3 ms (soundfile) | sounddevice 57.2 ms, miniaudio 36.8 ms |
| metadata, 10 min MP3 | **1.06 ms** | ~32 ms (soundfile) | header/probe path |
| decode 10 min WAV | 120 ms | **113 ms** (miniaudio) | soundfile 148 ms, pydub 116 ms |
| decode 10 min FLAC | **260 ms** | 278 ms (pydub) | soundfile 458 ms, librosa 608 ms |
| decode 10 min AAC/M4A | **353 ms** | 577 ms (pydub) | soundfile/miniaudio/librosa cannot read M4A |
| decode 10 min MP3 | 311 ms | **266 ms** (soundfile) | miniaudio 296 ms, pydub 598 ms |
| first sound, 10 min FLAC | **10.2 ms** | 475 ms (soundfile+sounddevice) | streaming, 39 MB RSS |
| playback overhead, 3 s | **+26 ms** | +216 ms (sounddevice) | Player keeps the device open |
| batch 2 FLAC | **260 ms** | 462 ms (soundfile) | load_many parallel |
| batch scaling, 8 short FLAC | 36 → 2 ms | — | 1 → 8 threads |
| peak RSS, streaming | **39 MB** | 252 MB (soundfile+sounddevice) | process-wide |
| soak, 200 plays | **+2.0 MB** | — | RSS 47 → 49 MB |

Trade-off: MP3 decode is now ~17% slower than libsndfile on this 10-minute file
(311 vs 266 ms) because minimp3 was removed for correctness and security. Both
are far above realtime. See the full tables below.

## Notes

- Decode workers normalize to float32: sound_rs, soundfile and librosa already return float32; miniaudio and pydub are converted from int16.
- pydub decodes through an ffmpeg subprocess; librosa uses soundfile/audioread. They are wrappers, not independent decoders.
- The `median` column is whole-worker wall time. `detail` shows in-process first-audio time, playback overhead, realtime factor or soak RSS.
- soundfile, librosa and miniaudio cannot open the AAC-in-MP4 corpus; pydub can via ffmpeg.
- Batch scaling uses eight copies of the 3-second FLAC corpus file.
- Peak RSS is process-wide and includes the interpreter and imports.
